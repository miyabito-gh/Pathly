# Pathly

Pathly は、ユーザーが明示的に登録したファイル・フォルダだけを、名前とタグで検索して開くデスクトップランチャーです。

## 初期実装の境界

- PC 全体の検索、登録フォルダ配下の自動走査、インデックス作成は行わない
- 通常検索は名前とタグ。ファイル名・保存場所は検索オプションで追加する
- SQLite へのアクセスは `PathRepository` 境界の内側に置き、将来のDB切替を妨げない
- ホームはお気に入り・最近使った・よく使うの切替式
- 項目を選択すると右詳細パネルを表示し、Enter で開く
- 管理機能はメイン画面から分離する

## 起動

```powershell
npm install
npm run dev
```

Tauri 実行時は `npm run tauri dev` を使用します。
