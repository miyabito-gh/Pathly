# Pathly

Pathly は、ユーザーが明示的に登録したファイル・フォルダだけを、名前とタグで検索して開くデスクトップランチャーです。

## 初期実装の境界

- PC 全体の検索、登録フォルダ配下の自動走査、インデックス作成は行わない
- 通常検索は名前とタグ。ファイル名・保存場所は検索オプションで追加する
- SQLite へのアクセスは `PathRepository` 境界の内側に置き、将来のDB切替を妨げない
- データ保存先は管理画面から変更できる。既定は開発時がプロジェクトルート、ビルド版が実行ファイルのあるフォルダー
- 保存先を変更すると現在のSQLiteデータベースを新しいフォルダーへ複製し、元のデータベースは自動削除しない
- ホームは登録項目全体を検索し、お気に入り・最近使った・よく使うの各一覧では、その一覧内を検索する
- 項目名クリックまたは Enter で開く。項目選択時は右詳細パネルを表示する
- 管理機能はメイン画面から分離する

## 起動

```powershell
npm install
npm run dev
```

Tauri 実行時は `npm run tauri dev` を使用します。
